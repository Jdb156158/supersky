# SUPER SKY · 萌宠会飞

根据提供的游戏视频制作的网页版：粉彩城市、五人飞行小队、彩虹尾迹、音符收集、连击、黑兔障碍与三颗生命。

## 本地运行

```sh
python3 -m http.server 4173 --directory dist
```

打开 http://localhost:4173 。无需安装依赖或构建。游戏图形使用 Canvas 实时绘制，音效由 Web Audio 合成；字体来自 Google Fonts，有本地系统字体回退。

## 操作

- `←` / `→` 或 `A` / `D`：在三条飞行路线间移动。
- 手机上点击左右按钮，也可以在画面上左右滑动。
- `Space`：开始、暂停、继续；`Escape`：暂停。
- 点击右上角音符开启 / 关闭声音，初始静音。
- 收集金色音符积累得分和连击；漏掉音符会中断连击。
- 撞到黑兔扣一颗生命，碰撞后有 1.2 秒保护；生命耗尽可重试。
- 一局 75 秒；最高分保存在当前浏览器。

## 检查

```sh
node --check dist/game.js
node --test tests/game.test.cjs
```

已覆盖换道边界、收集和连击、碰撞保护和失败重试、暂停继续、通关和最高分保存、路线可达性。

视觉与玩法根据 21 秒视频重建，并非原游戏资源或源码。视频未展示的规则采用三道收集、75 秒关卡和本地合成音效。
